# GT3 Dashboard Custom

Общение и документация — по-русски; интерфейс наследует английские подписи F1-дашборда.
Перед изменениями прочитай PROJECT_MAP.md, DATA_SOURCES.md и git status --short.

- Это отдельный проект и Git-репозиторий. Не менять соседний f1-dashboard-custom без запроса.
- Сохранять существующий стиль и отсутствие боковой панели. Проверять desktop/mobile.
- Только реальные бесплатные публичные данные. Не запускать генератор fake live.
- Исторические результаты, отсутствие канала, замерший поток и активную гонку различать явно.
- Не переносить CurrentDriverId из Combined Qualifying в гонку; не смешивать ID сессий.
- Отсутствующие GPS, радио, шины и погоду не заполнять выдумками. Карта — реальная геометрия.
- При смене данных обновлять нормализацию, UI, проверки и DATA_SOURCES.md согласованно.
- Нет обязательных внешних npm-зависимостей. Node.js 22+, npm start, npm test, npm run check.
- Поддерживать Windows. Пути пользователя не зашивать в исходный код.
- Обновлять PROJECT_MAP.md при архитектурных изменениях. Не коммитить и не публиковать без запроса.
